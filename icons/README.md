## Placeholder Icons for Odin's Eye Extension

This directory is intended to store the icons for the Odin's Eye Chrome extension.

Please add the following icon files here:

- `16x16.png` (16x16 pixels)
- `32x32.png` (32x32 pixels)

These icons will be used for the browser action button and by the extension internally.

For the MVP, if actual shield icons are not available, any distinct placeholder images can be used, or the emoji 🛡️ can be temporarily utilized directly in code where possible (though `manifest.json` requires file paths).

If using an SVG for the shield, ensure it's a clean and simple design that scales well to small sizes.
